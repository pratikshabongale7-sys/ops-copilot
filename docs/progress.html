The problem

On-call debugging, automated

When production breaks, an engineer spends the first 30 minutes pulling logs, scanning metrics, and checking recent deploys to find the cause.

Ops Copilot does that first pass automatically — and it maps directly onto a QA / reliability background: automating the diagnosis work, instead of doing it by hand.

reason → act → observe → conclude
How it works

The agentic loop

The agent is given one incident. It reasons, calls a tool to gather evidence, observes the result, and repeats — bounded by a step budget — until it can conclude.

Agent→ calls a tool → MCP server → logs / metrics / deploys → observe ↺ Diagnosis
